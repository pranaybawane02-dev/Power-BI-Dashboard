# Power-BI-Dashboard
                                                                                                          
📖 Overview                                                                                                                                                        
Developed an interactive Sales Performance Dashboard in Power BI to analyze key business metrics and support data-driven decision-making. The dashboard provides a clear overview of Sales, Profit, Cost, and Quantity through KPI cards and interactive visualizations.

It includes sales analysis by Category, Year, Customer, Country, and Segment, allowing users to identify top-performing categories, profitable customers, yearly sales trends, and customer segment contributions. A country slicer enables dynamic filtering, making the dashboard interactive and easy to explore.

✨ Key Features
📈 Interactive KPI Cards (Sales, Profit, Cost & Quantity)                                                                                                          
📊 Sales Analysis by Category                                                                                                                                      
🌍 Country-wise Sales Comparison                                                                                                                                   
👥 Customer Segment Analysis
