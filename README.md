# Power-BI-Dashboard
Sales Performance Dashboard 

Developed an interactive Sales Performance Dashboard using Power BI.
Analyzed and visualized sales data to identify business trends and performance.
Created KPI cards to display Sales, Profit, Cost, and Quantity.
Designed interactive visualizations, including bar charts, line charts, scatter charts, and donut charts.
Added a Country slicer to filter the dashboard dynamically.
Analyzed sales performance by category, customer, year, country, and segment.
Identified top-performing customers based on profit.
Compared sales and quantity across different countries.
Displayed customer segment distribution (Consumer, Corporate, and Home Office).
Designed a clean and user-friendly dashboard to support data-driven decision-making.
